# Noman Javed - Portfolio

This is my personal portfolio website. It has a short bio, my skills, and my contact info.

## What is on the page

- **About Me**: A short paragraph about me and my background.
- **My Skills**: A simple list of skills (Python, Machine Learning, Data Analysis, HTML and CSS).
- **Contact Me**: My email address and a button that opens a new email to me.

## Tech stack

- HTML
- CSS (all styles are written inside the `index.html` file, there are no extra files or frameworks)

## How to view

1. Download or clone this repo.
2. Open `index.html` in any web browser.

No setup or build step is needed.
